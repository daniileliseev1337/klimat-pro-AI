# Онбординг-навигатор — design (brainstorm 2026-07-03, решения владельца)

## Решения brainstorm (зафиксировано с владельцем 03.07.2026)
1. **Путь: A+B+C поэтапно.** Этап 1 (первым): B «раздел Помощь» + C «CommandPalette как навигатор».
   Этап 2 (потом, отдельной фичей): A тур-coachmarks при первом входе.
2. **Аудитория: ВСЕ роли.** Один механизм, контент фильтруется по роли:
   сотрудник/админ — полный набор (Дашборд, Проекты, Задачи, Финансы, Аналитика, Клиенты, Админ,
   импорт выписок, отчёты, бэкап, команда/права); заказчик — свои 4 вкладки (Дашборд, Проекты,
   Задачи, Финансы: что видно, как принимать задачи, заявки); посетитель — минимум (что доступно, как запросить полный доступ).

## Этап 1 — объём (следующая сессия: план → код)
- **Справочник разделов** — единый источник: массив `HELP_SECTIONS` (id, title, роль-фильтр, описание
  2-3 предложения, «как открыть», иконка из уже импортированных lucide). Отдельный файл `src/lib/helpContent.js`
  (НЕ в App.jsx — новые куски отдельными файлами, см. CLAUDE.md).
- **Раздел «Помощь» (B)**: модалка в стиле premium-dark (реюз Modal/Card/SectionTitle), список секций
  по роли текущего юзера. Точки входа: иконка «?» в шапке рядом с колоколом + пункт в ProfileModal.
- **CommandPalette (C)**: дополнить команды описаниями из `HELP_SECTIONS` (строка-сабтайтл),
  + команда «Помощь» открывает модалку B. Palette уже умеет разделы — расширить, не переписывать.
- **Критерии приёмки**: у каждой роли в «Помощи» только свои разделы (§1: заказчик не видит намёков
  на себестоимость/доли/чужие разделы); Cmd+K находит раздел по названию и описанию; вход с телефона —
  модалка скроллится и читается; vitest на фильтрацию `helpContent` по ролям.

## Этап 2 — тур A (НЕ в этом заходе)
- Coachmarks поверх вкладок при первом входе, повторный запуск из «Помощи»; хранение «видел» —
  localStorage (`kp-tour-seen`), в профиль не пишем (YAGNI, per-device достаточно — допущение,
  пересмотреть при жалобах на «тур снова вылез»).

## Не делаем (осознанно)
- Никакого нового state-management/роутинга — всё в существующей модели вкладок.
- Не документируем в справке админ-фичи для не-админов; контент «Помощи» — на русском.
