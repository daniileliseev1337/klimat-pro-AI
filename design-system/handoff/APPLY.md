# КЛИМАТ-ПРО · Жидкое стекло — как применить

Обновление меняет только **стиль карточек**. Правок в `App.jsx` не требуется —
всё завязано на классы `.kp-card` / `.glass-card` / `.gold-ingot`.

## Что внутри
- **`index.css`** — твой стиль с новым материалом: тёмная smoke-тонировка тела +
  настоящая рефракция живого фона (`url(#lg-warp)`) + ярче/изящнее золотая кромка.
- **`liquid-glass-filters.html`** — SVG-фильтры рефракции (нужно подключить один раз).

## Шаги
1. Замени `src/index.css` на этот `index.css` (или перенеси изменённые блоки:
   токен `--glass-tint`, правила `.kp-card`, `.glass-card`, `.gold-ingot::before`,
   `.kp-card::before` и оба `@supports`-фолбэка).
2. Подключи SVG-фильтры **одним из способов**:
   - **Проще:** вставь `<svg>`-блок из `liquid-glass-filters.html` в `index.html`
     сразу после `<body>`; **или**
   - в `main.jsx` перед `createRoot(...)` инжектни его в `document.body`
     (я уже показывал этот вариант — чистый DOM, вне дерева React).
3. `npm run build` → раскатка как обычно.

## Важно про Safari / iPhone (PWA)
`backdrop-filter: url(#lg-warp)` в WebKit **не поддерживается** — на iOS/Safari
рефракции не будет, карточки останутся сочным тёмным тонированным стеклом с яркой
золотой кромкой (деградация мягкая, выглядит достойно). Полная рефракция — в
Chrome/Edge (десктоп) и Android Chrome.

## Опционально: «максимальная» iOS-линза по кромке
Гелевый преломляющий ободок по краю карточки требует одного слоя-спана внутри
компонентов `Card` / `KpiCard` (фильтр `#lg-rim` уже включён в набор). Скажи —
добавлю точечно.
