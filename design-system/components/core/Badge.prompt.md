Status pills. Use semantic `tone`, or pass a `color` hex to match a project stage / category.

```jsx
<Badge tone="success" dot>Оплачен</Badge>
<Badge tone="warning">Дедлайн близко</Badge>
<Badge color="#2dd4bf" dot>Сдан заказчику</Badge>
```

Tones: `neutral · gold · success · warning · danger · info`. Sizes `sm | md`.
