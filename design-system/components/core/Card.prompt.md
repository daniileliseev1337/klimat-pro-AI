The universal surface. Plain by default; `gold` adds the signature metallic edge — reserve it for the most important card on a view.

```jsx
<Card>
  <h3 style={{margin:0,fontSize:16}}>Проект «Корпус B»</h3>
  <p style={{color:"var(--text-muted)"}}>Стадия: В работе</p>
</Card>

<Card gold padding={22}>Премиальная карточка с золотой рамкой</Card>
```

Props: `gold` (ingot edge), `hover` (lift+glow, default on), `spotlight` (cursor warmth, default on), `padding`.
