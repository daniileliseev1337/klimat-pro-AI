## Грабли среды (проверено многократно, не переизобретать)
- **Диск F: сбоит на fsync** (EUNKNOWN у Edit/Write-тулов, зависшие build). Обход: писать контент на C:
  и переносить python-скриптом (append/copy без os.fsync). git: `-c core.fsyncMethod=writeout-only` + ретрай.
- **Edge-функции с кириллицей в пути** деплоить ТОЛЬКО `cp` с /mnt/f (см. deploy/admin-create-user/…sh).
  `Get-Content | wsl` stdin ДРОПАЕТ UTF-8 байты → Deno «could not find an appropriate entrypoint».
- **Многострочный bash в WSL** — только файлом: `Get-Content -Raw x.sh | wsl bash -c 'tr -d "\r" > /tmp/x; bash /tmp/x'`.
  Инлайн `wsl bash -c "…"` из PowerShell ломается на `2>`, `$?`, кавычках.
- **VPN Happ (sing-box/xray, TUN)**: в профиле маршрутизации ОБЯЗАН быть Direct IP `193.124.130.236/32`,
  иначе frp-туннель рвётся и сайт снаружи отдаёт 502 (инцидент 03.07.2026, простой 6ч). Диагноз:
  `journalctl -u frpc` = `connection write timeout` серией. frpc сам реконнектится, рестарты не нужны.
- **GitHub-доступ зависит от сети**: при активном VPN — git push с ДЕФОЛТНЫМ окружением (без обхода прокси);
  без VPN — может понадобиться системный прокси. Если connect timeout — попробуй другой вариант.
- Пути с кириллицей (`F:\Сайт`) всегда в кавычках; `/mnt/f/Сайт/...` из WSL работает.
